📱 Android Phone GitHub & Deployment Guide (No PC Needed)

  1. Download Project Zip: Save ai-loan-collection-agent.zip on your Android phone and extract it using the built-in Android Files app.
  2. Upload to GitHub on Android: Open Chrome or the GitHub Mobile App on Android, create a Private Repository named ai-loan-collection-agent, tap Add file → Upload files, and commit the extracted folders (never upload a real .env file).
  3. Deploy Backend from Mobile Browser: Sign in to Render.com or Railway.app on Android Chrome, connect your GitHub repo, set start command uvicorn backend.main:app --host 0.0.0.0 --port $PORT, and paste your environment variables from .env.example.
  4. Add Dashboard to Android Home Screen: Open the deployed URL in Chrome on Android and tap Menu (⋮) → Add to Home screen for 1-tap mobile access.

🔒 Safe Telephony Configuration & Testing Protocol

  1. Step 1 (Sandbox Verification): Keep TELEPHONY_PROVIDER="simulator" in .env and verify all 6 Hindi intents, PTP dates, and RBI hour blocks in the dashboard first.
  2. Step 2 (Whitelist Only Your Own Phone): Register with Exotel (India TRAI compliant) or Twilio, and add only your own personal phone number as a verified test recipient.
  3. Step 3 (Configure Webhooks): Set PUBLIC_WEBHOOK_BASE_URL to your HTTPS backend domain so Twilio/Exotel can reach /api/telephony/twilio/twiml and /api/telephony/twilio/gather.
  4. Step 4 (Audit Check): Confirm that the AI asks for identity confirmation first before reading out the masked loan number and EMI amount.
